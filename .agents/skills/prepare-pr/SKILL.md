# Prepare Pull Request

Do not push or create a PR without explicit user approval.

Before preparing the PR:

1. confirm working tree state
2. confirm tests and validation evidence
3. inspect the complete diff
4. identify breaking changes
5. identify migrations
6. identify unresolved risks
